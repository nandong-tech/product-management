# project_prds/

Project-specific AIDR PRDs (tenant / operator implementations).

**Not used yet for day-to-day authoring** — the team is currently building the **prebuilt** catalog under `prebuilt_prds/` (e.g. `LF-*`).

When `generate-prd` runs with target **project**, new files are saved here, often seeded from a matching prebuilt in `prebuilt_prds/`.

Do not put catalog/prebuilt LF files here.
